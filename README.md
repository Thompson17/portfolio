### Chess WebSocket Server

A web server component developed as part of an academic assignment on distributed systems. It handles bidirectional communication between browser-based clients and remote server components using WebSockets and Java RMI.

[View code sample →](java/chess-websocket-server/)

### Unity Behaviour Trees

The reference solution for a Unity workshop that I prepared during my studies. It demonstrates autonomous character behaviour through behaviour trees, resource management, navigation and environmental perception.

[View code sample →](csharp/unity-behaviour-trees/)

### Minesweeper Game Logic

The core game logic of an academic Android project, demonstrating recursive flood fill, randomised mine placement, neighbourhood calculations and game state management. The sample focuses on the underlying algorithms and data structures rather than the graphical user interface.

[View code sample →](java/minesweeper-game-logic/)

### Geometric Objects

An implementation of a predefined object-oriented class structure for two-dimensional and three-dimensional geometric objects, demonstrating inheritance, polymorphic cloning, operator overloading and exception handling.

[View code sample →](cpp/geometry-oop/)

Minor technical corrections and documentation improvements were made during portfolio preparation in November 2026. The samples have not been compiled or runtime-tested as part of this process.

Further information about the scope, implementation and authorship of each sample is provided in its individual README.
