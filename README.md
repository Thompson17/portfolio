# What does this repository contain?

This repository contains code examples written by me. These were created during my university studies and are sorted by programming language.

Due to this, some of the examples are in German.

## C++
The assignment focussed on inheritance and the task was to implement the given class diagram. _main.cpp_ was supplied by the lecturer to test our solution. All other classes were written by me.

## C#
This code was written as part of Unity workshop that I prepared, where the participants had to complete and implement a behaviour tree using [Panda BT](http://www.pandabehaviour.com/). The code here is my sample solution that I presented at the end of the workshop.

## Java
This is part of an assignment, where a I wrote a server for a online chess game. The clients (browser) are connected to the web server via sockets, which is connected to the game server via RMI. The code here is the implementation of the web server.
