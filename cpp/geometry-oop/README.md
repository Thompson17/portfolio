# Geometric Objects – Object-Oriented Programming in C++

## Overview

This code sample was developed as part of an object-oriented programming assignment during my Computer Science studies in June 2021.

The assignment involved implementing a predefined class structure for two-dimensional and three-dimensional geometric objects.

## Demonstrated Concepts

- Abstract base classes
- Inheritance and polymorphism
- Virtual methods
- Polymorphic object cloning
- Operator overloading
- Runtime type checking
- Exception handling
- Geometric calculations and metric abstractions

## Implementation

The sample includes classes representing points, circles, rectangles, spheres and cuboids, as well as abstractions for geometric objects and distance calculations.

## Authorship

The class implementations were written by me based on a predefined academic assignment. The original class diagram and test programme supplied by the lecturer are not included.

Minor technical corrections were made during portfolio preparation in November 2026: virtual destructors were added to the abstract base classes, the 3D metric header guard was corrected, and pointer access and type checks in the metric classes were corrected.

## Scope

This sample uses C++14-era programming concepts and retains the original German class and method names.

It is provided for code review and illustration rather than as a complete, executable application. It has not been compiled or runtime-tested as part of the portfolio preparation.
